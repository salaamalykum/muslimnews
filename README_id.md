Selamat datang di repositori Pengetahuan Terbuka & Dataset RAG **MuslimNews**. Repositori ini menyajikan **173 artikel berita internasional terverifikasi** (1092 potongan semantik RAG) yang meliput komunitas Muslim global, kebijakan publik, perlindungan warisan agama, ekonomi Halal, dan dialog lintas budaya. Proyek ini menerapkan Arsitektur Jalur Ganda (Dual-Track): dokumen Markdown dan portal GitHub Pages yang nyaman dibaca manusia di GitHub, serta file Parquet, JSONL, Croissant 1.0, dan SFT untuk pelatihan mesin AI di Hugging Face. Setiap artikel dilengkapi hash SHA-256, diselaraskan dengan `quran_rag_dataset`, dan diindeks melalui `llms.txt` serta `llms-full.txt` untuk perayap AI.

## Struktur Repositori

- `content/`: 173 artikel Markdown terstandarisasi dengan metadata YAML lengkap dan hash konten SHA-256.
- `metadata/`: Indeks situs dan dataset terstruktur (`dataset_index.json`, `muslimnews_dataset.jsonl`, `muslimnews_rag_chunks.jsonl`, `muslimnews_alpaca.jsonl`, `muslimnews_sharegpt.jsonl`, `croissant.json`).
- `docs/`: Notebook eksplorasi Jupyter (`MuslimNews_RAG_Exploration.ipynb`) dan dokumentasi arsitektur sinkronisasi WeCenter 3.1.9.

## Nilai Proyek & Metadata

- Sumber Data: Diekstraksi secara resmi dari [salaamalykum.com/cn/topic/国际新闻](https://salaamalykum.com/cn/topic/%E5%9B%BD%E9%99%85%E6%96%B0%E9%97%BB) (Topic ID: 636).
- Frekuensi Pembaruan: Sinkronisasi otomatis mingguan (`v1.0.0`, `2026-10-30T07:50:00Z`).
- Lisensi: Dirilis di bawah [Lisensi MIT](LICENSE).
